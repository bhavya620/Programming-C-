# Assignment 4 – Separate C++ Programs and Outputs

This folder contains one standalone C++17 program for each of the six tasks in Assignment 4, plus a separate output text file for each program.

## Compile and run
Example:
```bash
g++ -std=c++17 -Wall -Wextra Task01_Class_Design_Review.cpp -o task1
./task1
```
Use the corresponding source filename and executable name for Tasks 2–6. On Windows PowerShell, run `.	ask1.exe`.

## Files
- Task01: payroll hierarchy and runtime polymorphism
- Task02: Person/Student/Staff/TeachingAssistant virtual diamond
- Task03: base/member construction, destruction and the supplied Student constructor completion
- Task04: static binding, virtual dispatch, virtual destructor and slicing
- Task05: Cart methods, `this`, chaining, pointer/reference/direct/dynamic access
- Task06: extensible vehicle rental hierarchy and fleet

The `_Output.txt` files contain the output produced by compiling and running these programs with g++ using C++17. Compiler version and platform may affect minor formatting or diagnostics.
